Web εφαρμογή για λογιστικά γραφεία

Admin CRM

Πίνακας ελέγχου για τη διαχείριση του πελατολογίου ενός λογιστικού γραφείου. Όλοι οι πελάτες, τα βασικά τους στοιχεία και τα στατιστικά, σε μία οθόνη.

Τύπος
Web εφαρμογή
Χρήστες
Λογιστικά γραφεία
Γλώσσα
Ελληνικά

Τι φτιάξαμε

  • Πίνακας ελέγχου: σύνολο πελατών, ενεργοί πελάτες, έγγραφα και νέοι πελάτες του μήνα.
  • Γράφημα κατανομής ανά νομική μορφή (ΟΕ, ΑΕ, ΙΚΕ) και λίστα πρόσφατων πελατών.
  • Κάρτες πελατών με ΑΦΜ, νομική μορφή, κατάσταση, email, τηλέφωνο και διεύθυνση.
  • Αναζήτηση με όνομα ή ΑΦΜ, φίλτρα και κουμπί «Νέος Πελάτης» για γρήγορη καταχώριση.
  • Web app
  • CRM
  • Πελατολόγιο

Web εφαρμογή ενημέρωσης

Λογιστικά Νέα Portal

Μια πύλη που μαζεύει τα νέα για τον λογιστικό και φορολογικό κόσμο από πολλές πηγές, ώστε να μη χρειάζεται να τις ψάχνει κανείς μία μία.

Τύπος
Web εφαρμογή
Χρήστες
Λογιστές και επιχειρήσεις
Γλώσσα
Ελληνικά

Τι φτιάξαμε

  • Συγκεντρωμένα άρθρα από πολλές πηγές, με τίτλο, περίληψη, πηγή, θέμα και ημερομηνία.
  • Αναζήτηση με λέξεις-κλειδιά και φίλτρα ανά πηγή.
  • Ενότητα «Προθεσμίες» δίπλα στα άρθρα.
  • Σκούρο θέμα με δυνατότητα αλλαγής σε φωτεινό και ένδειξη πότε ενημερώθηκε τελευταία φορά το περιεχόμενο.
  • Web app
  • Ενημέρωση
  • Dark / Light mode

Επέκταση browser

Customer Care Master Tool

Μια επέκταση για τον browser που δίνει στην ομάδα εξυπηρέτησης πελατών ό,τι χρειάζεται στο ίδιο σημείο: συνδέσμους, διαδικασίες και έτοιμες απαντήσεις, χωρίς αλλαγή καρτέλας.

Τύπος
Επέκταση browser
Χρήστες
Ομάδες εξυπηρέτησης
Προσαρμογή
Ανά ομάδα

Τι φτιάξαμε

  • Ενιαία αναζήτηση σε εργαλεία, διαδικασίες και έτοιμες απαντήσεις.
  • Χρήσιμοι σύνδεσμοι (CRM, escalations, Slack, βάση γνώσεων) σε κάρτες που ανοίγουν με ένα κλικ.
  • Αναζητήσιμες διαδικασίες, π.χ. καθυστερημένη παράδοση, κατεστραμμένο προϊόν, ακύρωση παραγγελίας.
  • Λόγοι επικοινωνίας σε μορφή διαδρομής, ώστε να καταχωρούνται σωστά.
  • Έτοιμες απαντήσεις με κουμπί «Copy» για αντιγραφή με ένα κλικ.
  • Browser extension
  • Εξυπηρέτηση πελατών
  • Productivity
